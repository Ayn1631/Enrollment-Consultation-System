# 项目分析资料

本目录用于沉淀可直接服务毕业设计报告撰写的项目分析材料，重点覆盖系统定位、总体架构、技术栈、模块划分、数据流程、部署方式、创新点与现阶段不足。

文件说明：

- `01-系统架构与技术栈分析.md`：面向项目理解与论文设计章节的完整分析。
- `02-毕业设计正文素材.md`：可直接改写后写入论文正文的正式表述版本。
- `03-技术栈证据清单.md`：按“技术/用途/代码依据”整理的可追溯清单，方便答辩或老师追问时核对。

使用建议：

1. 写“系统总体设计”时优先参考 `01` 和 `02`。
2. 写“开发环境与技术选型”时优先参考 `03`。
3. 若论文需要强调严谨性，建议将“当前已实现能力”和“预留但未形成主链路的组件”分开描述，避免把预留架构写成已稳定上线能力。
